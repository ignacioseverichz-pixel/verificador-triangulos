# Verificador de triángulos

Aplicación de consola desarrollada en Python.

El programa solicita las medidas de los tres lados de un triángulo y determina si es:

- Equilátero: sus tres lados son iguales.
- Isósceles: tiene dos lados iguales.
- Escaleno: sus tres lados son diferentes.

También verifica que los valores ingresados sean positivos y que puedan formar un triángulo.

## Ejecución

Para ejecutar el programa se utiliza:

```bash
python main.py
